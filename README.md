# Smart Contactless Classroom

A Python-based Smart Contactless Classroom System designed to automate attendance management using computer vision and facial recognition technologies.

## Features

* Automated student attendance tracking
* Face recognition-based identification
* Student record management
* Attendance report generation
* User-friendly interface
* Contactless classroom management

## Technologies Used

* Python
* OpenCV
* NumPy
* SQLite
* Tkinter (if used)

## Project Structure

```text
Smart Contactless Classroom/
├── main.py
├── database/
├── images/
├── models/
├── requirements.txt
└── README.md
```

## Installation

1. Clone the repository:

```bash
git clone https://github.com/mangalamshrivastava61-hash/smart-contactless-classroom.git
```

2. Navigate to the project directory:

```bash
cd smart-contactless-classroom
```

3. Install dependencies:

```bash
pip install -r requirements.txt
```

4. Run the application:

```bash
python main.py
```
